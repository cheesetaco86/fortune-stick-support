求籤與生命之書 支援

聯絡方式：請在 GitHub Issues 建立新的 Issue（需要 GitHub 帳號）。Issue 內容會公開顯示，請不要貼上日記或夢境原文，也不要留下個人資料；描述操作步驟、iOS 版本與看到的畫面即可。

常見問題

我的日記和夢境存在哪裡？
只存在這台裝置上本 App 的專用空間。本 App 不需要帳號，也不會把內容上傳到伺服器。

換手機時資料會跟著走嗎？
本 App 沒有雲端同步。若你用 iCloud 或電腦備份並在新裝置還原，系統備份可能包含本 App 的資料；實際結果依 iOS 備份設定而定。

夢的反思是在預測未來嗎？
不是。反思內容是依你寫下的字詞，從 App 內建的離線文字目錄挑選的開放式問題，用來陪你整理感受，沒有標準答案，也不預測未來。

籤詩與生命之書的解說代表一定會發生嗎？
不代表。這些文字是反思的起點，不保證任何結果，也不能取代醫療、法律、財務等專業建議。

夢境日記顯示「暫時無法開啟」怎麼辦？
App 不會刪除或覆蓋無法開啟的夢境資料，其他功能仍可正常使用。請先更新到最新版本並重新開啟 App；若仍無法開啟，請建立 Issue 描述發生前的操作（不必附上夢境內容）。

如何刪除紀錄？
在日記、顯化或夢境的內容頁使用刪除按鈕。刪除 App 會一併移除裝置上的 App 資料，但不會刪除你既有的系統備份。

支援哪些裝置？
首發支援搭載 iOS 17 或更新版本的 iPhone。
